A single Li-ion cell can power Rodeo, through a charger and a buck-boost on the
motherboard. A MAX17048 fuel gauge on the I²C bus (address `0x36`) reports its
state of charge.

## Proposed shape

```cpp
rodeo::Battery bat;

bat.Init(i2c);
float pct = bat.Percent();        // 0..100, or < 0 with no cell
if(bat.Low())                     // below the save threshold
    SaveStateAndDim();
```

## What the Seed cannot see

The charger's power-good and charging outputs and the source mux's status do
not reach the Seed. The board also cannot tell a 500 mA USB port from a 1.5 A
one, so LED brightness should default low.
