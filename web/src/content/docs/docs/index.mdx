Everything here describes **Rev B**, the version the campaign ships. It is written
for the person deciding whether to build on this platform, which means it leads
with the connectors, the contracts and the dimensions rather than the pitch.

:::caution[Early hardware, and some of this is still on paper]
The first Rev B run arrived on 28 October 2026 and bring-up has been running
since: nine of the eleven tests have passed, so a good deal of what follows has
now been measured rather than designed. Not all of it. Treat anything without a
date as a design intention, check the badge on
[the board itself](/ecosystem/), and read the faults bring-up found — a reversed
battery connector and a codec trace too close to its neighbours — beside the
motherboard.
:::

## What is not here yet

The firmware side lives in [rodeo-sdk](/sdk/). Enclosure drawings and a panel
template are still to be written. So is a bring-up guide, which no longer waits
on hardware — it waits on someone writing down what the last fortnight taught.
