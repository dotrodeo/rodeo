Everything here describes **Rev B**, the version the campaign ships. It is written
for the person deciding whether to build on this platform, which means it leads
with the connectors, the contracts and the dimensions rather than the pitch.

:::caution[No board has been built yet]
The motherboard and all seven daughterboards were ordered from JLC on 18 October 2026
for a first run of five of each, so these designs are final — but none has arrived,
been assembled or been powered on yet. **Nothing on these pages has been measured
on hardware.** The measurements that do exist came off the earlier prototype, and
[that page](/prototype/) covers what it demonstrated.
:::

template and the Rev B bring-up guide are still to be written — they wait on
boards to bring up.
